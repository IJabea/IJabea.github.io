# Ibrahem AlJabea — complete website

Start with START_HERE.md. This package includes all eight LSU-themed pages, images, documents, the interactive publication world map with Universities and Article dropdowns, website-guide chat, the AI backend, and daily Google Scholar update files.

The site can be viewed immediately by opening index.html after unzipping. AI and scheduled imports are prepared but require the account setup described in START_HERE.md. No private keys are included. The live GitHub website is not updated until the files are uploaded and deployed.

The university names are consolidated in the Universities dropdown. Collaborator details appear after selecting a university or map marker. Article filtering limits the university options to that article.

The map currently includes five articles, 45 mapped coauthors and 13 countries. Seven people have unresolved locations. New imports use known directory locations or remain pending; they do not prove an affiliation for a new paper. Read the sources and affiliation notes on the page.
