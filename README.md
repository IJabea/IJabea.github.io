# Ibrahem AlJabea — GitHub Pages website

Migrated from the public Wix website on September 18, 2026. This is a responsive redesign, preserving the source text and accessible document links. Research status and teaching history match the Wix source and may need updating.

## Publish
1. Extract this ZIP.
2. Open https://github.com/IJabea/IJabea.github.io/upload/main
3. Upload all files and the assets folder INSIDE this folder into the repository root. Replace index.html. Do not upload the ZIP itself or an enclosing folder.
4. Commit changes. The existing GitHub Pages site should rebuild.
5. If needed: Settings → Pages → Deploy from a branch → main → / (root) → Save.
6. Visit https://ijabea.github.io after deployment finishes.

The home-page Curriculum Vitae label on Wix did not expose a downloadable link; no CV has been invented. Add a CV PDF and link when available. Downloaded PDFs are included in assets; external research links remain external. Wix-specific widgets and animations are replaced by static, accessible HTML.

## Edit
Edit the corresponding HTML file to update each page. Shared styling is in style.css. No installation, subscription, build process, or JavaScript is required.
